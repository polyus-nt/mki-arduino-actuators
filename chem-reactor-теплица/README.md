# Arduino вентиляторов теплицы-химреактора

Отдельная прошивка в `arduino-actuator`, не фаблаб-профиль второй UNO.
Один шлюз **14**, два вентилятора с индексами **0/1**.

Откройте [arduino-actuator.ino](arduino-actuator/arduino-actuator.ino),
выберите **Arduino Uno**, установите **PinChangeInterrupt 1.2.9** через Library Manager.
Соседние репозитории для сборки не нужны.
Карта пинов: [BoardConfig.h](arduino-actuator/BoardConfig.h).

| Вентилятор | PWM | Тахометр | Реле питания |
| --- | --- | --- | --- |
| 0 | D10 | D8 | A0 |
| 1 | D11 | D12 | A1 |

Эта аппаратная карта совпадает с фаблаб-проектом `arduino-actuator-2`.
Прошивки не взаимозаменяемы: у химреактора адрес 14, API idx=0/1,
нет режимов неисправности; у ФабЛаб адрес 17, глобальные idx=4/5.

| Сигнал Austere | Пин UNO |
| --- | --- |
| MISO | D2 |
| MOSI | D3 |
| CLK | D4 |
| CS | D5 |
| IRQ | D6 |

При переходе со старой карты перенесите провод IRQ Arduino с D7 на D6
и обновите эту прошивку. Вывод IRQ шлюза не меняется.

PWM=0 → реле LOW, выключено; PWM>0 → HIGH, включено. При старте реле LOW до OUTPUT.
Старт: PWM=0. При потере связи последнее PWM удерживается.
Тахометр: API_PULSES_PER_REV=2, проверьте для своего вентилятора.
PID/температурных решений и режимов неисправности нет.
PWM применяется как передан; старые команды 0x40/0x41 отклоняются.
Общий замок и релейный вентилятор находятся на lmp8, не здесь.

Нативные проверки из этой папки: `py -3 scripts/test_firmware.py --cxx g++`.
Другие репозитории не нужны.
Полная карта: `tjc-sketch/chem-reactor-теплица/PINOUT.md`.
Сервис/HTTP-консоль: `tjc-commutator/chem-reactor-теплица/`.

## USB TEST

В BoardConfig.h включите `#define TEST`, загрузите прошивку.
Serial Monitor: 9600 бод, Newline; `pwm 0`, `rpm 0`, `set_pwm 0 100`,
затем `set_pwm 0 0`. Для второго вентилятора idx=1. Это физическое управление;
после проверки выключите оба канала и верните обычную сборку без TEST.
[Полная инструкция проверки](../../tjc-commutator/docs/TESTING.md).
