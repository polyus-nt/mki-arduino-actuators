# Arduino Actuator

Актуальная прошивка: [arduino-actuator.ino](arduino-actuator.ino).
В проекте один скетч: старый PID, температурное управление, EEPROM и legacy удалены.
Arduino выполняет только аппаратные команды для шести вентиляторов.

## Arduino IDE

1. Откройте `arduino-actuator.ino` из папки `arduino-actuator`.
2. Выберите Arduino Uno (проверенная сборка; модель платы для стенда ещё уточняется).
3. Нажмите «Проверить». В конфигурации по умолчанию внешние библиотеки не нужны.
4. Для реальных каналов задайте карту в [BoardConfig.h](BoardConfig.h) и установите
   **PinChangeInterrupt 1.2.9** через менеджер библиотек.

По умолчанию неизвестные выходы выключены, операции вентилятора возвращают
NOT_IMPLEMENTED. Сборка без карты — проверка кода, не готовая прошивка стенда.
Нужны массивы `API_PWM_PINS` и `API_TACH_PINS` по шесть пинов.
Вся распиновка и количество импульсов на оборот находятся только в
`BoardConfig.h`: транспорт задаётся полной группой из пяти `API_LINK_*`.
Частичная транспортная карта останавливает сборку с ошибкой.
PWM-пины должны поддерживать analogWrite, таховходы — PinChangeInterrupt.
Пересечения между PWM, тахо и транспортом запрещены.
Транспорт по умолчанию: MISO=D2, MOSI=D3, CLK=D4, CS=D5, IRQ=D7.
D3/D5 занимают два PWM Uno: для шести аппаратных PWM нужна другая согласованная разводка.

## Поведение

PWM 0..255; чтение и подтверждение установки возвращают фактически применённый PWM.
RPM передаётся как u32, без старой нормализации.
mode=1 меняет PWM выбранного вентилятора сразу и каждые 30 секунд;
mode=2 случайно заменяет только поступающие ему команды установки.
Одновременно активен один сценарий для одного вентилятора.
При потере связи, выключении или смене режима последний PWM сохраняется.
После включения питания PWM=0, mode=0. Замки и пылесос обслуживает восьмилампочница.

## Структура и проверки

- `src/ActuatorApi.h` — обработчики команд и сценарии.
- `src/BoardIO.h` — GPIO, тахометры, проверка карты.
- `src/common/HardwareProtocol.h` — бинарный кадр 20 байтов с CRC.
- `src/austere/` — локальная AustereSerialMaster с лицензией upstream.
- `src/main.cpp` — только адаптер PlatformIO; Arduino IDE собирает корневой .ino.

```sh
pio run -e uno
pio run -e uno_compile_check
```

Вторая конфигурация проверяет шестиканальный код с намеренно конфликтующей картой.
Её карта находится в `test/compile_only_board.h`; числовые пины не задаются
в `platformio.ini`, подключается только файл конфигурации.
Её нельзя прошивать на стенд.
[Протокол и межрепозиторные проверки](../tjc-commutator/docs/FIRMWARE-IMPLEMENTATION.md).
Старый код восстанавливается из истории Git, отдельной legacy-прошивки нет.
