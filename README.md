# Два самостоятельных проекта Arduino Actuator

В этом репозитории две отдельные прошивки Arduino IDE. Переключателя платы нет:

| Проект | Открыть в Arduino IDE | Вентиляторы API | Локальные индексы | Шлюз |
| --- | --- | --- | --- | --- |
| Первая UNO | [arduino-actuator-1.ino](arduino-actuator-1/arduino-actuator-1.ino) | 0..3 | 0..3 | 14 |
| Вторая UNO | [arduino-actuator-2.ino](arduino-actuator-2/arduino-actuator-2.ino) | 4/5 | 0/1 | 17 |

Обе папки самостоятельны: у каждой собственные `.ino`, `BoardConfig.h`, `src/`
и `platformio.ini`. Можно скопировать любую папку целиком и собрать без соседнего
проекта. Старого корневого скетча и переключения конфигурации больше нет.

## Arduino IDE

1. Через **Файл → Открыть** откройте нужный `.ino` из таблицы.
2. Выберите **Arduino Uno** и COM-порт соответствующей платы.
3. Установите **PinChangeInterrupt 1.2.9** через менеджер библиотек.
4. Нажмите **Проверить**, затем **Загрузить**.
5. Для второй Arduino откройте второй проект; менять конфигурацию первой не нужно.

Распиновка находится в отдельном `BoardConfig.h` выбранного проекта:
[первая плата](arduino-actuator-1/BoardConfig.h), [вторая плата](arduino-actuator-2/BoardConfig.h).

### Первая Arduino — четыре вентилятора

| Индекс API / локальный | PWM | Тахометр | Реле |
| --- | --- | --- | --- |
| 0 / 0 | D10 | D12 | A0 |
| 1 / 1 | D11 | D13 | A1 |
| 2 / 2 | D6 | A4 | A2 |
| 3 / 3 | D9 | D8 | A3 |

### Вторая Arduino — два вентилятора

| Индекс API / локальный | PWM | Тахометр | Реле |
| --- | --- | --- | --- |
| 4 / 0 | D10 | D12 | A0 |
| 5 / 1 | D11 | D13 | A1 |

На обеих платах Austere: MISO=D2, MOSI=D3, CLK=D4, CS=D5, IRQ=D7.
Каждая подключается к своему шлюзу. Хаб сохраняет единый внешний node14
и индексы0..5, переводит4/5 в node17 idx0/1, восстанавливает реквизиты ответа.
На аппаратной линии каждая Arduino принимает только собственный node и локальный idx.

## Поведение

PID, температурных правил, EEPROM и legacy нет. Arduino выполняют аппаратные команды.
PWM0..255; get_pwm и ответ set_pwm возвращают фактически применённое значение.
При PWM=0 реле HIGH (питание выключено); при PWM>0 реле LOW (включено),
затем analogWrite. Старт: реле HIGH до OUTPUT, PWM=0.
Без связи последнее состояние удерживается.

RPM передаётся unsigned u32 без нормализации, обновляется примерно раз в секунду.
`API_PULSES_PER_REV=2` — предположение, проверить по модели вентилятора.
Тахометр D13 проверить на реальной UNO/клоне со встроенным LED.
Конфликты PWM/тахо/реле/транспорта отклоняются до доступа к GPIO.
Неправильные размеры массивов и неполная карта Austere — ошибка сборки.

Режим1 задаёт случайный PWM сразу и каждые30с; режим2 искажает только новые
команды выбранного вентилятора. Каждая плата выполняет свой сценарий,
а хаб координирует единственную неисправность во всей системе.
Возврат в режим0 не восстанавливает прежний PWM. Потеря связи не прекращает режим1.
User/Admin — логические группы API; токенов прошивка не требует.

## Состав каждого проекта

- `BoardConfig.h` — фиксированные адрес, количество каналов и вся распиновка.
- `src/ActuatorApi.h` — команды с подробными русскими комментариями.
- `src/BoardIO.h` — GPIO, RPM и проверка карты.
- `src/common/HardwareProtocol.h` — бинарный кадр28байтов с CRC.
- `src/austere/` — локальная AustereSerialMaster и лицензия upstream.
- `src/main.cpp` — только адаптер PlatformIO для собственного `.ino`.

Копии общего core намеренно находятся внутри обеих папок ради самостоятельной
сборки Arduino IDE. Изменения core нужно вносить в оба проекта; тест ниже
проверяет совпадение копий. Пины не копировать между проектами — они разные.

## Проверки и альтернативная сборка

Нативные тесты обоих проектов (Python3 и компилятор C++11):

```powershell
py -3 scripts/test_projects.py
```

Они проверяют синхронизацию core, API, реле/PWM/RPM, локальные адреса/индексы,
безопасный порядок GPIO и отклонение конфликтующей карты.
Это не замена проверки электрических уровней и реального оборудования.

Arduino CLI из корня репозитория:

```powershell
arduino-cli compile --fqbn arduino:avr:uno arduino-actuator-1
arduino-cli compile --fqbn arduino:avr:uno arduino-actuator-2
```

PlatformIO:

```powershell
pio run --project-dir arduino-actuator-1
pio run --project-dir arduino-actuator-2
```

Сборка не загружает код автоматически; выбирайте нужную Arduino при прошивке.
